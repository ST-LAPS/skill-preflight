# Product experiment

## Completed in v0.1.0
- Dependency-free local scanner and CLI.
- Text, JSON and Markdown reports, explicit exit codes.
- Good and intentionally broken example bundles.
- Automated regression tests and documented limits.

## Next gates
1. Benchmark on at least 10 diverse public skill repositories, record commit SHA and each finding. Inspect static content only.
2. Manually label findings as useful, false positive, or ambiguous. Do not count ambiguous warnings as bugs.
3. Fix systematic false positives before public promotion.
4. Publish a free preview and GitHub-native installation instructions when results justify it.
5. Track repeated adoption and explicit requests for private-repo policy/history features. Stars alone are not purchase intent.
6. Validate a paid offer before implementing subscriptions. Marketplace eligibility and publisher verification remain outstanding.

## Not built
Hosted service, GitHub App, payment collection, access management, behavioral skill evals, marketplace listing, and analytics.

No revenue, customers, or adoption are claimed.
